WHY IT WORKS

从教材中的三个关键方程理解

小扰动理论不是“把翼型画薄一点”这么简单。关键步骤是先在参考直线上满足边界条件，再用叠加的扰动速度计算表面压力。

01 / ASSUMPTION

把大问题变成小量问题

V = V∞ + V′，其中 V′ = (u′, v′)

假设二维、定常、不可压、无黏且无旋，并且迎角（弧度）、翼型表面斜率和扰动速度都足够小。于是 |u′|/U∞、|v′|/U∞ ≪ 1，可以忽略二阶乘积。这里“小”的核心是斜率与扰动，而不只是厚度数值小。

02 / TANGENCY

流体不能穿透翼型表面

v′±/U∞ ≈ dy±/dx − α

实际不可穿透条件是 v/u = dy/dx。对小迎角和小斜率展开后，就得到上式。它说明：表面斜率决定流线必须偏转多少；迎角 α 则改变来流相对表面的方向。上、下表面用 ± 区分。

03 / BERNOULLI

速度的变化怎样成为压力变化

Cp = 1 − |V|²/U∞² ≈ −2u′/U∞

精确的速度平方含有 u′²、v′² 等二阶项，也包含与迎角相关的高阶乘积。忽略这些项后，压力变化对轴向扰动速度呈线性。因此可以先把三个扰动速度相加，再把三项一阶 Cp 相加。

把迎角、弯度和厚度分成三项，究竟分的是什么？

沿弦向的速度扰动可写成 u′ = u′α + u′m + u′s；法向速度同样叠加。线性理论的可叠加对象是速度势、速度和一阶压力系数，不是未经线性化的动压，也不是“迎角的升力 + 厚度的升力”这种对所有真实流动都成立的结论。

VORTEX & SOURCE SHEETS

为什么弯度和迎角对应涡片，厚度对应源汇片？

VORTEX SHEET / γ

迎角 + 弯度 → 上下表面速度差

迎角和中弧线让翼型上下表面需要不同的切向速度，用沿弦向分布的涡片来表示。这里采用顺时针为正的片强度 γ，与保角变换页面采用的逆时针正环量约定不同。

u′+ − u′− = γ

上表面速度增加、压力降低；下表面反之，形成压力差并贡献升力。这个例子对应的解析分布为：

γ/U∞ = 2α√[(1−X)/X] + 16m√[X(1−X)]

第一项由迎角产生，第二项来自本页采用的抛物线中弧线。它满足尾缘 γ(1) = 0 的库塔条件；公式不能直接推广到任意弯度线。

SOURCE SHEET / q

厚度 → 流体向上下两侧绕行

厚度让上、下表面相对中弧线向外偏移，可以在零厚度参考线上布置源汇片。源强为正表示局部向外排流，为负表示吸入；其正、负变化来自半厚度的斜率。

q(x) = 2U∞ dys/dx

本页厚度分布得到 q/U∞ = πt cos(πX)，前半弦为源、后半弦为汇；因为翼型闭合，沿弦积分的净源强为零。

∫₀ᶜ q(x) dx = 0

厚度会改变两侧共同的压力分布，但在此一阶薄翼模型中不产生上下表面的净压力差，因此不改变一阶 CL。

为什么小扰动模型会预测升力？

压力差 ΔCp = Cp,下 − Cp,上 = 2γ/U∞。沿弦积分得到一阶升力系数：

CL = ∫₀¹ ΔCp dX = 2π(α + 2m)

α 必须用弧度，m 是弯度比。对于这个特定的抛物线中弧线，零升力迎角为 αL=0 = −2m（弧度）。例如 m = 0.02、α = 0 时仍然有正升力；而 α = m = 0、仅有厚度时，一阶升力为零。

MODEL BOUNDARIES

什么时候不能相信这套近似？

前缘奇异性

理想零厚度薄翼在非零迎角下，涡片强度可能在前缘按 1/√X 发散。图表避开端点只是避免绘图故障，并不意味着前缘真实流动符合小扰动假设。

大迎角或厚翼

迎角、表面斜率和局部扰动不再足够小时，二阶项不再小；大迎角可能发生黏性分离或失速，这个势流近似完全无法预测。

不能拿虚线当真值

虚线使用的是同一个一阶速度解，只是把速度平方项加回去。它可以演示线性化遗漏了什么，却不能代替更高阶模型、保角变换的同几何解或实验数据。

学习建议：依次点击「只看迎角」「只看弯度」「只看厚度」，观察涡片 γ、源汇片 q 和上、下表面的 Cp 是否同步改变，再打开三者叠加。与 Joukowski 保角变换实验 对照时，要先确认几何是否一致。
