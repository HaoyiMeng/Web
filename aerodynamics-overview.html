LEARNING MAP

模型与方法的关系

势流理论是共同的物理基础，奇点分布与保角变换是不同的求解方法，而薄翼理论增加了小扰动假设。二维与三维的区别来自几何维度，不是求解精度的简单排序。

势流基础 → 奇点分布

源心、涡心 → 源面与涡面 → 诱导速度与跳跃定理

二维翼型 / 完整几何

保角变换（适合已知映射的翼型）与 Hess–Smith 面元法 是不同求解方法；后者直接使用翼型边界。

面元法通过不可穿透条件与库塔条件求速度，再由伯努利计算压力。

二维翼型 / 一阶近似

小扰动与切向条件 → Glauert 薄翼理论（求 γ） → 压力系数与升力（由 γ 求气动力）。

三维空气动力学

三维涡面与涡丝 → 自由涡面与诱导速度 → 普朗特升力线理论（后续专题）。

升力线理论同时利用二维翼型的升力关系与三维尾涡的诱导速度。
