THE QUESTION

已知 α 与 dym/dx，如何求出 γ(x)？

不是凭空假设一个涡量曲线，而是由无穿透边界条件确定它。最后的未知量会变成一组可计算的系数 A₀、A₁、A₂ …

01 / OVERVIEW

这三页笔记究竟在解什么？

薄翼理论把有厚度的真实翼型简化为弦线附近的一组理想奇点。已知翼型上下表面 y⁺(x)、y⁻(x) 和迎角 α，先将几何分成中弧线与半厚度，再分别处理：

GEOMETRY / 几何分解ym = (y⁺ + y⁻)/2　　ys = (y⁺ − y⁻)/2
迎角 α + 中弧线 ym→涡片 γ→升力半厚度 ys→源片 q→厚度流场

这是二维、定常、不可压、无黏、无旋外流中的一阶线性薄翼近似。此处 α、表面斜率和扰动速度比均视为小量。位于零厚度弦线上的奇点是数学表示，并不是实体翼型中存在真实的“涡层”或“喷水孔”。

符号 / Symbol含义 / Meaning
c（笔记写作 ℓ）翼弦长度；前缘 x = 0，后缘 x = c。
U∞（笔记写作 V∞）远场来流速率；α 为小迎角，所有公式中的 α 用弧度。
ym、ys中弧线（camber line）和半厚度（half thickness）。
γ(x)、q(x)涡片强度与源片强度，单位均为速度。本站 γ 取产生正向升力的符号，等于上、下两侧切向扰动速度之差。
PV柯西主值（Cauchy principal value）；处理 x′ = x 时积分核的奇性。
A₀、AₙGlauert 展开系数；A₀ 与迎角及平均弯度斜率相关，高阶系数来自中弧线几何。

02 / SCELTA DELLA DISTRIBUZIONE DI SINGOLARITÀ

为什么迎角、弯度用涡片，而厚度用源片？

笔记首先比较三个极限问题。判断依据不是“哪种奇点更好看”，而是上下两侧为了满足不穿透条件，需要哪一种速度跳跃。

01 / LAMINA PIANA

平板存在迎角

上下两侧平均法向扰动相同，但切向速度存在跳跃：u′⁺ − u′⁻ = γ₁(x)。因此采用涡片。

02 / LAMINA CURVA

弯板零迎角

两面共享同一中弧线斜率，也需要切向速度差，使用另一部分涡片 γ₂(x)。

03 / PROFILO SIMMETRICO

对称厚翼零迎角

上下表面斜率相反，需要法向速度的跳跃，使用沿弦分布的源片 q(x)。

厚度的源片强度怎样求？

对称厚翼在 α = 0 时，有 y⁻ = −y⁺。源片在参考弦线两侧诱导法向速度 v′⁺ = +q/2、v′⁻ = −q/2；上表面线性切向条件给出 dy⁺/dx = v′⁺/U∞。于是：

SOURCE SHEET / 源片q(x) = 2U∞ · dys/dx

若前后缘半厚度都为零，∫₀ᶜ q(x)dx = 2U∞[ys(c) − ys(0)] = 0。前半部可以是源、后半部是汇，但总源量为零。源片的轴向扰动在上下两侧相同，所以一阶压力差为零；理想对称翼型在零迎角时不产生升力。

关键区分：源片对应上下两侧法向速度的跳跃；涡片对应切向速度的跳跃。这解释了为什么升力问题主要研究 γ，而不是 q。

03 / BOUNDARY CONDITION

由切向边界条件推出奇异积分方程

中弧线记为 ym(x)。真实物理条件是流体速度必须沿翼面切向，不能穿透。小斜率近似后，参考弦线上的法向扰动速度满足：

TANGENCY / 线性化切向条件dym/dx = α + v′(x)/U∞

涡片在上下两面诱导相同的法向速度，但产生相反的切向扰动速度：

u′γ,+ = +γ(x)/2　　u′γ,− = −γ(x)/2

它在弦线上的共同法向速度通过二维涡的 Biot–Savart 叠加得到。注意 x′ 是积分变量，x 是观察点；当 x′ → x，必须按主值理解积分：

INDUCED VELOCITY / 涡片法向诱导速度v′(x) = −(1/2π) PV ∫₀ᶜ γ(x′)/(x−x′) dx′

将其代回切向条件，得到 Glauert 方法的出发点：

FUNDAMENTAL INTEGRAL EQUATION / 基本积分方程(1/2π) PV ∫₀ᶜ γ(x′)/(x−x′) dx′ = U∞[α − dym/dx]

右侧的 α 和中弧线斜率已知；未知的是整个函数 γ(x′)。接下来进行坐标变换与级数展开，就是为了把这一函数方程变成代数系数问题。

本页涡片强度采用 γ = u′⁺ − u′⁻ 的正升力约定。若在其他教材中使用逆时针为正的环量 Γccw，其环量符号可能相反；不要只对照符号而忽略方向约定。

04 / GLAUERT TRANSFORMATION

为什么把 x 换成 θ？

原积分核包含 x − x′，而涡片在前缘可能具有平方根奇性。Glauert 采用半圆投影作为新坐标，把弦向区间映射为角区间 0 ≤ θ ≤ π：

COORDINATE TRANSFORM / 半圆映射x = (c/2)(1 − cos θ)，　dx = (c/2)sin θ dθ

图是投影坐标的示意，不是翼型真正的几何外形。变换后，积分分母变为 (c/2)(cos θ′ − cos θ)，微分 dx′ 则提供 sin θ′。这样三角积分可以用标准恒等式处理。

选择满足后缘条件的涡片展开

GLAUERT SERIES / 涡片强度γ(θ) = 2U∞ [ A₀(1 + cos θ)/sin θ + ∑n=1∞ Aₙ sin(nθ) ]

A₀ 项来自有迎角平板的标准解；后面是以 sin(nθ) 为基底的弯度修正。对尖锐后缘，在 θ → π 时这些项都趋于零，因此满足线性理论的 Kutta 后缘条件 γ(c) = 0。

相反，θ → 0 时，A₀(1+cos θ)/sin θ ≈ 2A₀/θ，意味着非零 A₀ 会带来前缘奇性。数学上的前缘发散不能被误认为真实黏性流场有无限速度。

05 / SINGULAR INTEGRALS

把级数代入原方程，如何消去积分？

把 x、x′ 都换成角坐标

x − x′ = (c/2)(cos θ′ − cos θ)，dx′ = (c/2)sin θ′ dθ′。代入后 c/2 相消，留下仅关于 θ 和 θ′ 的主值积分。

把涡片展开拆成 A₀ 和 Aₙ 两组

积分左侧化为 U∞/π [A₀G₀(θ) + ∑n≥1AₙGₙ(θ)]。这一步正对应课堂笔记第三页右下角标出的 G₀ 与 Gₙ。

使用标准的主值积分恒等式

当 0 < θ < π 且 n≥1 时，下列两个积分有解析结果。这里的正负号取决于我们已经固定的分母 cos θ′ − cos θ。

THE TWO KEY IDENTITIES / 两个关键积分G₀ = PV ∫₀π (1 + cos θ′)/(cos θ′ − cos θ) dθ′ = π
Gₙ = PV ∫₀π sin θ′ · sin(nθ′)/(cos θ′ − cos θ) dθ′ = −π cos(nθ)

于是左边成为 U∞[A₀ − ∑n≥1Aₙ cos(nθ)]，与右侧 U∞(α − dym/dx) 比较，并约去 U∞：

REDUCED FOURIER EQUATION / 化简后的主方程A₀ − ∑n=1∞Aₙ cos(nθ) = α − dym/dx

移项得到另一种更适合提取系数的写法：

dym/dx = (α − A₀) + ∑n=1∞Aₙ cos(nθ)

这就是第一张笔记框出的结果。重要的转换已经发生：几何斜率函数被写成一组余弦系数。

06 / FOURIER ORTHOGONALITY

如何一步步提取 A₀ 和 Aₙ？

先求 A₀：把方程直接积分

从 0 到 π 对 θ 积分。因为 n≥1 时 ∫₀π cos(nθ)dθ = 0，所有高阶项消失：

∫₀π [dym/dx]dθ = π(α − A₀)
ZEROTH COEFFICIENT / 零阶系数A₀ = α − (1/π) ∫₀π [dym/dx]dθ = α − αID

这里 αID = (1/π) ∫₀π (dym/dx)dθ 称作理想迎角（incidenza ideale）：使 A₀ = 0，也就是消除该级数前缘 A₀ 奇性项的迎角。

再求 Aₙ：乘 cos(mθ) 后积分

在同一方程两边乘 cos(mθ)，m ≥ 1，然后对 θ ∈ [0,π] 积分。常数项的积分为零，且余弦族满足正交性：

ORTHOGONALITY / 余弦正交性∫₀π cos(mθ)cos(nθ)dθ = { π/2 （m=n≥1）； 0 （m≠n） }

无限级数里只有 n=m 的那一项保留下来：

∫₀π [dym/dx]cos(mθ)dθ = (π/2) Am
HIGHER COEFFICIENTS / 高阶系数Aₙ = (2/π) ∫₀π [dym/dx]cos(nθ)dθ，n ≥ 1

注意积分里的导数仍是 dym/dx，不是 dym/dθ。你要先使用 x(θ) 将翼型斜率表达成 θ 的函数，然后按 θ 积分，不能漏掉变量之间的关系。

这段推导真正用到的核心数学工具只有三角函数的正交性。A₀ 是斜率的平均项（连同迎角），而 Aₙ 是斜率投影到 cos(nθ) 上的结果。

07 / PHYSICAL OUTPUT

有了 Aₙ，升力和压力差怎样求？

在涡片约定下，上、下侧切向速度之差为 γ，因此线性化伯努利关系给出下表面减上表面的压力系数差：

ΔCp = Cp,lower − Cp,upper = 2γ(x)/U∞

单位展长环量定义为 Γlift = ∫₀ᶜγ(x)dx。把 Glauert 级数和 dx = (c/2)sinθ dθ 代入，只有 A₀ 和 A₁ 在全弦积分后留下贡献：

CIRCULATION / 正升力约定的环量Γlift = π U∞ c (A₀ + A₁/2)
THIN-AIRFOIL LIFT / 二维升力系数CL = 2Γlift/(U∞ c) = 2π(A₀ + A₁/2)

理想迎角 αID

A₀ = 0 时的迎角，即 αID = (1/π)∫₀π y′m(θ)dθ。

零升力迎角 αL=0

CL = 0 时的迎角，即 αL=0 = αID − A₁/2。

这是一个容易混淆但重要的区别：消除 A₀ 项不等于消除总环量。有弯度时，即使 A₀ = 0，A₁/2 仍能贡献升力。

08 / INTERACTIVE EXAMPLE

自己改变迎角与弯度，观察 A₀、A₁ 和 γ(x)

为了得到可核对的解析结果，实验固定使用抛物线中弧线 ym/c = 4mX(1−X)，X = x/c。此处 m 是最大弯度比，没有厚度项。

dym/dx = 4m(1−2X) = 4m cos θ　⇒　A₀ = α，A₁ = 4m，An≥2 = 0

课堂笔记对应的三个可手算结果

FLAT PLATE / 平板

仅有迎角

y′m = 0 ⇒ A₀ = α，Aₙ = 0。γ/U∞ = 2α√[(1−X)/X]；CL = 2πα。

CIRCULAR ARC / 圆弧弯板

笔记中的 β

若课堂采用 y′m = 2β cos θ，则 A₀ = α，A₁ = 2β，其余为零；α = 0 时仍有 CL = 2πβ。

PARABOLIC CAMBER / 抛物线

当前交互几何

ym/c = 4mX(1−X) ⇒ A₁ = 4m；CL = 2π(α + 2m)，αL=0 = −2m（弧度）。

09 / LIMITATIONS & REVIEW

什么时候不能直接使用这些公式？

前缘与后缘的处理不同

后缘采用 Kutta 条件选定物理解；前缘若 A₀ ≠ 0，零厚度模型出现理想奇性。图表绕开端点不等于前缘真实流场被正确求解。

大迎角、厚翼与黏性现象

本节不能预测失速、分离、摩擦阻力或非线性激波，也不应把一阶压力差当作任何真实翼型的精确压力分布。

复习时可以用四个问题自检

  1. 为什么迎角和弯度使用涡片，而对称厚度使用源片？
  2. 涡片诱导速度带入切向边界条件后，为什么会出现 PV 主值积分？
  3. 为什么 θ 变换能把积分方程化成余弦级数？
  4. 为什么 A₀ = 0 不一定意味着 CL = 0？

可把这篇作为推导参考，再进入已有的小扰动实验观察 Cp、q、γ 的变化。两页的交互几何使用相同的抛物线中弧线定义，但 Glauert 页专注于涡片与 Fourier 系数，小扰动页还包含厚度对应的源片。
